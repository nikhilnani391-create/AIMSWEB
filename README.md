# 3D Space Shooter

A 3D-perspective space shooter game built with HTML5 Canvas and JavaScript.

## How to Play

Open `index.html` in any modern browser — no build step or server required.

### Controls

| Key | Action |
|---|---|
| WASD / Arrow Keys | Move ship |
| Space | Fire |
| Shift | Boost speed |
| Enter | Start / Restart |

### Features

- **3D perspective** with vanishing-point projection and depth-scaled sprites
- **Three enemy types**: Fighter, Scout (fast zigzag), Cruiser (heavy armor)
- **Five power-ups**: Shield, Rapid Fire, Spread Shot, Extra Life, Bomb
- **Combo scoring** — chain kills for multiplied points
- **Level progression** with increasing difficulty
- **Visual effects**: particle explosions, screen shake, engine glow, nebula background, perspective grid

## File Structure

```
index.html   — Game page with UI overlay and styles
game.js      — All game logic, rendering, and state management
```
